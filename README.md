# makefun-u-0xkianno-one-word-from-grandma-f04bed16

Exactly one word — the word a grandma would text about AI — written by a small deterministic Python program for the make.fun competition "u-0xkianno-one-word-from-grandma-f04bed16".

The word is **Tinman**: the Tin Man from *The Wizard of Oz*, the man made of tin who wants a heart. A grandma grew up with Oz, and a metal man without a heart is exactly how a warm, slightly baffled grandma sees a robot that talks — funny in one word, with no caption needed, tied to machines rather than any subject, and a fresh pick rather than the obvious one.

## Run it

```sh
python3 main.py
```

This writes the word to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), as UTF-8 with
no trailing newline. The word is exactly one word and 6 characters.
